      Clique un élément pour centrer la carte dessus.

      Calque « jeu » : couleurs de PALETTE.IFF. Couleur de base du triangle = celle du sommet le plus haut (comparaison non signée) ; teinte du sommet = première + (éclairage × n + 128) ÷ 256 ; teinte interpolée puis tramage en damier. Non reproduits : textures du sol (dessinées par le jeu par-dessus la teinte ; l'option « cases texturées » les montre), brouillard (seuils absents). Non établi : la diagonale des carrés (réglable) ; le tramage suit ici les pixels de la carte, pas ceux de l'écran. Pistes : octet « couleur » pris comme index de palette. Les enregistrements d'objets ne sont pas dans DATA_MODEL : leur disposition est un constat sur le fichier.
